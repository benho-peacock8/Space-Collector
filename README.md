# Space Collector

My project is a simple interactive space game where the player controls a spaceship using the keyboard. The player collects stars to earn points while avoiding rocks. The project uses multiple sprites, variables, loops, conditional statements, and a custom block with an input.

## Controls

Use the arrow keys to move the spaceship.

## Features

- Collect stars to increase the score.
- Avoid rocks.
- Lose points when hitting a rock.
- Custom block with an input.
